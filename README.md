# AI Structure Decorator (EditorAI base)

This repository integrates source code from [Entity12208/EditorAI](https://github.com/Entity12208/EditorAI) into `magmituber/AI-Structure-Decorator`.

- Build target: Android64 only.
- Gemini model default: `gemini-3.1-flash-lite`.
- Gemini API key: intentionally blank; enter it in the mod's local settings on your device. Never commit API keys.
- Imported engine and UI: `src/main.cpp`, `src/overlay.cpp`, `src/sessions.hpp`, `src/design_knowledge.hpp`.

Mobile layout and text entry still require validation on an actual Android device before release.
