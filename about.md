# AI Structure Decorator

An Android-focused Geometry Dash editor mod. Select a structure, choose a style in the mod settings, and ask Gemini to generate a bounded list of decorative object placements.

The mod validates AI output before creating objects. The API key is entered locally in Geode settings and is not included in the source code.

This is an early version: generated placements use conservative limits and should be checked in the editor before saving a level.
